# Наш проект ко Дню независимости Республики Казахстан 🇰🇿

Официальный веб-сайт школьного проекта учеников **8 «В» класса Меновновской средней школы**, посвящённого Дню независимости Республики Казахстан.

## Состав проекта

- `index.html` — основная страница сайта (адаптивная семантическая вёрстка HTML5).
- `style.css` — оформление сайта в современном минималистичном стиле (CSS3, градиенты, карточки, адаптация под мобильные устройства и ПК).
- `script.js` — двуязычный интерфейс (`RU` / `ҚАЗ`), автоопределение языка браузера, сохранение выбора в `localStorage` и плавная анимация появления элементов.
- `README.md` — документация и инструкция по запуску и публикации.

---

## Как открыть сайт локально

1. Скачайте и распакуйте архив `menovnovskaya-school.zip` в любую удобную папку.
2. Откройте файл `index.html` двойным щелчком мыши (он откроется в любом современном браузере: Chrome, Safari, Edge, Firefox, Яндекс Браузер).
3. Установка дополнительных программ или запуск локального сервера не требуется.

## Как опубликовать сайт на GitHub Pages

1. Создайте бесплатный аккаунт на [GitHub](https://github.com) (если его ещё нет).
2. Нажмите **New repository** (Создать репозиторий) и укажите имя, например: `independence-day-project`.
3. Выберите тип репозитория **Public** и нажмите **Create repository**.
4. Нажмите **uploading an existing file** и перетащите внутрь все файлы из папки `menovnovskaya-school` (`index.html`, `style.css`, `script.js`, `README.md`).
5. Нажмите зелёную кнопку **Commit changes**.
6. Перейдите во вкладку **Settings** (Настройки) → раздел **Pages** в левом меню.
7. В блоке **Build and deployment** → **Branch** выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
8. Через 1–2 минуты в верхней части страницы появится готовая ссылка вида `https://ваш-логин.github.io/independence-day-project/`, которой можно делиться со всеми.
